# Code of Conduct

## Our Standards

- Be respectful and constructive in all interactions
- Focus on what is best for the community and the project
- Accept constructive criticism gracefully
- No harassment, discrimination, or offensive language

## Scope

This code of conduct applies to all project spaces — GitHub issues, pull requests, and any other communication related to this project.

## Enforcement

Violations may result in removal from the project community. Report issues by opening a private issue or contacting the maintainer directly.
